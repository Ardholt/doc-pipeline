# Document proof

`hero.png` uses unscaled text-field and checkbox crops from the actual blank and filled trip-permission PDF rasterizations. The two fields are shown as separate detail crops with captions; the original full-page layout is in the linked PDF and PNG downloads. `../output/preview-map.json` records every source pixel rectangle and destination.

The document workload exports sanitized DOCX files through LibreOffice, removes PDF metadata and rasterizes with Poppler. The page screenshots in `../output/page-previews/` use the shared offline GitHub frame and Pages layout. They are not captures of published URLs.
