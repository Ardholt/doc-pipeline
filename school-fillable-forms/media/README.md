# Document proof

`hero.png` is the filled trip-permission page rendered from its PDF by Poppler, cut below its last line; nothing is redrawn. `../output/preview-map.json` records the source file and the crop rectangle.

The document workload exports sanitized DOCX files through LibreOffice, removes PDF metadata and rasterizes with Poppler. The page screenshots in `../output/page-previews/` use the shared offline GitHub frame and Pages layout. They are not captures of published URLs.
