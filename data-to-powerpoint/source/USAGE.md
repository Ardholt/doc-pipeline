# Inputs and delivery

`data.csv` must have exactly `period,department,revenue,cost` as its header. Period is YYYY-MM. Department is an anonymous uppercase code, starting with a letter, with optional digits, underscores or hyphens; maximum length is eight characters. Revenue and cost are nonnegative decimal money, with at most two decimal places and a maximum of 999999999.99 per cell. No blanks, thousands separators, duplicate period/department pairs or incomplete period/department grids are accepted. Negative profit is valid.

`deck.json` contains `schema_version: 1`, a single-line `title` of up to seventy characters, a three-letter uppercase `currency`, `department_order` covering every department exactly once, and `colours` mapping every department to `#RRGGBB`. Additional descriptive keys are ignored. Use neutral titles and codes, without names or contact details.

The supported range is one to twelve departments and one to twenty-four periods. Overview pages group up to six departments; comparison and trend pages group up to three departments; trends split into windows of up to three periods. Periods sort chronologically. Independent profit axes are labelled on the slide; they include zero and all negative values. Revenue/cost comparisons use a common scale within each slide. Totals are exact Decimal sums; native Office number cells use numeric floating-point storage, checked against the decimal representation.

From the case folder, use `./run.sh --input "/absolute/input directory" --output "/absolute/output directory"`. Spaces work. Inputs are mounted read-only; generated files go only to the output directory. Output must be separate from input. Use a dedicated output directory: named generated files are replaced, and earlier slide images are removed. Invalid inputs return a specific error and a nonzero exit status.

Use `./run.sh --check` with the same optional input/output arguments to inspect existing files without conversion or rebuilding. It requires the image created by the first run. The pipeline checks chart caches and embedded workbooks, editable text, source maps, axis ranges, rendered totals, metadata and hashes. `tests/regression.py` also exercises deliberate damage and validator rejection cases. Run `./tests/acceptance.sh` after the initial build to repeat the complete pipeline, check unchanged document content, and exercise reordered departments, cents and extra periods. Its report is `output/acceptance.json`. Reports contain actual tool versions; `packages.tsv` records the full installed package inventory.

`Dockerfile` records the shared pinned base recipe; the runner uses `../harness/Dockerfile` with the Impress and python-pptx groups selected in `run.sh`. No private image is needed for cold setup. The initial build needs network access. The workload has no network access and uses a fresh LibreOffice profile, C.UTF-8 locale and UTC timezone. The case fontconfig file restricts document and screenshot rendering to the DejaVu files listed in `output/font-inventory.json`.

Compatibility was checked by opening and rendering the cleaned PPTX in LibreOffice, then rendering the cleaned PDF with Poppler. Microsoft PowerPoint and Excel were not run. General financial correctness beyond the supplied revenue/cost definition, accessibility certification and application-specific layout parity are not claimed.
